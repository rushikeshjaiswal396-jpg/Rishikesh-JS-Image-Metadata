# Rishikesh-JS-Image-Metadata
Python based image metadata extractor
Rishikesh-JS-Image-Metadata

A Python-based Image Metadata Extractor

A simple Python tool for inspecting image information and metadata.

Features

- Image file information
- Image format and dimensions
- EXIF metadata inspection
- Metadata viewing from supported images
- Command-line based tool

Requirements

- Python 3
- Pillow

Installation & Usage

1. Install Python

Install Python 3 on your computer.

2. Clone the repository

git clone https://github.com/YOUR-USERNAME/Rishikesh-JS-Image-Metadata.git

3. Open the project folder

cd Rishikesh-JS-Image-Metadata

4. Install dependencies

pip install -r requirements.txt

5. Run the tool

python Rushi.py

Requirements

- Python 3
- Pillow
