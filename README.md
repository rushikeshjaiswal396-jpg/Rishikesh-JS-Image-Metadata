Rishikesh-JS-Image-Metadata

A Python-based Image Metadata Extractor

A simple Python tool for inspecting image information and metadata.

Features

- Image file information
- Image format and dimensions
- EXIF metadata inspection
- Metadata viewing from supported images
- Command-line based tool

Requirements

- Python 3
- Pillow

Installation

pip install Pillow

Usage

python Rushi.py

Supported Formats

Formats supported by the installed image library may include JPG, JPEG, PNG and others.

This tool is intended for educational purposes and legitimate image metadata inspection.
